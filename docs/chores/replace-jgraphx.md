# Replace jgraphx

`com.github.vlsi.mxgraph:jgraphx` is a fork of the dead JGraphX. It still gets occasional releases from a single
maintainer. grep finds three Java files using `com.mxgraph`.

Check what the graph is used for. Options: keep the fork (and watch its release activity), move to a maintained graph
library, or draw the few graphs with Java2D.

## Done when

Either the replacement is in place and `jgraphx` is removed from the POMs, or the decision to keep it is recorded here and the chore is deleted.
